# 補貨姓名與口味分組（2026-11-18）

首次勾選或取消「需要補貨」填姓名即可。儲存確認後，同一分頁 30 分鐘內沿用姓名；重新整理或關閉分頁後重填。姓名會隨異動保存，這不是登入或身分驗證，不再需要認證碼。

飲料、零食、冰品、泡麵與碳粉有正數入庫、成功保存且庫存大於 0 時，自動取消該品項的補貨勾選。到貨頁、快速入庫與批次入庫共用規則。更新數量／盤點不會取消，錯誤、未送出或儲存失敗也不會先取消。重試不重複入庫；入庫中斷後才重新勾選的標記會保留。

零食庫存把同一品名整合成一組，各口味直接分行。例如：

```text
宴麥森林綜合纖脆燕麥棒
    杏仁芝麻     4 條    □ 需要補貨    ＋快速入庫
    巧克力風味   4 條    □ 需要補貨    ＋快速入庫
```

每個口味保留原 ID、數量、補貨勾選與歷史，也能個別編輯或更新數量。某口味入庫，只取消該口味的勾選。同一品名的其他口味保留。搜尋、分類和庫存條件仍以各口味篩選，桌機與手機都只顯示一次組內品名。

## 已有 Google 部署的更新

1. 用最新完整 [Code.gs](../google-apps-script/Code.gs) 取代原專案內容並儲存。
2. 點「部署 → 管理部署 → 編輯」，版本選「新版本」，部署。
3. 重新整理網站。回應中的 `websiteEntry.restockAuthVersion` 為 `2` 才能啟用姓名補貨登記。

沿用原 `/exec` 網址、試算表與資料，不重跑 `setupOnce`。原 `HOLDWIN_RESTOCK_PIN` 指令碼屬性不再採用，不需要另外設定。首次寫入會在 `RestockPreferences` 原七欄後補上第八欄「登記人」，保留舊資料；若欄位已有其他用途，會拒絕寫入並提示確認。
